تطبيق أحباب مكة PWA - نسخة أولية مجانية

1) افتح config.js وضع رقم واتساب الشركة ورقم الاتصال بصيغة 9647... دون +.
2) ارفع جميع الملفات والمجلد icons إلى جذر مستودع GitHub عام.
3) من Settings > Pages اختر Deploy from a branch ثم main و /(root) واضغط Save.
4) افتح رابط GitHub Pages الذي يظهر بعد النشر عبر Chrome على سامسونگ.
5) من قائمة Chrome (⋮) اختر تثبيت التطبيق أو إضافة إلى الشاشة الرئيسية.

ملاحظات:
- يحتاج التثبيت إلى رابط HTTPS (مثل GitHub Pages) وليس فتح ملف HTML محلياً.
- صور المعرض الحالية رموز توضيحية، وليست صور رحلات حقيقية.
- الحجز يفتح واتساب بعد تعبئة النموذج؛ لا توجد قاعدة بيانات أو لوحة إدارة بعد.
- عند تعديل ملفات التطبيق، حدّث CACHE في sw.js من v1 إلى v2 لضمان تحديث الملفات المخزنة.
